About Kamado

Portfolio answers and a few prepared jokes appear immediately. Open-ended questions load local AI on demand. It runs a small generative model on your device using WebAssembly; WebGPU is not required. The first visit downloads model and runtime files, which the browser may cache. Loading and replies depend on your internet connection, memory and processor.

No API key, subscription or paid inference service is used. Internet data, device power and website hosting are separate. Messages are not sent to an AI provider. The last 120 messages and their timestamps are saved in local storage on this browser until you clear history or browser data. They do not sync across devices. Model downloads send ordinary network request metadata to their hosts.

The assistant retrieves relevant facts from Ali’s published portfolio. It does not browse the internet or perform actions. It can make mistakes. If the model cannot run, prepared answers are labelled “Portfolio guide”. No model was trained from scratch for this site.

Generated replies are buffered in a background browser worker and shown as complete messages. The five-second countdown is a status check, not a promised completion time. If AI takes longer, the indicator shows elapsed time. Timestamps use the device’s timezone, not IP geolocation; the USA has multiple timezones. Kamado uses a Tanjiro-inspired fan avatar and is not the official anime character. Optional reply sound can be enabled in chat.

Powered by SmolLM2 and Transformers.js. SmolLM2 and Transformers.js use Apache-2.0; ONNX Runtime uses MIT. Runtime licenses are supplied beside the worker files.
